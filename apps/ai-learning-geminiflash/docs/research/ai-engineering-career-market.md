# AI ENGINEERING CAREER & MARKET REQUIREMENTS DOSSIER
**Research Date:** 2026 AI Engineering Ecosystem Snapshot

---

## 1. Target Role A: Navisoft-Style AI Engineer Archetype
- **Profile:** Enterprise AI & Data Science Engineer combining deep algorithmic modeling with legacy and scalable enterprise data pipelines.
- **Core Technical Requirements:**
  - Python & C/Java fundamentals, Bash scripting.
  - Classical Machine Learning: Scikit-Learn, XGBoost, CatBoost, feature engineering, imbalanced datasets.
  - Deep Learning & NLP: TensorFlow, PyTorch, Transformers, embeddings, sequence models.
  - Mathematical & Statistical Rigor: Linear algebra, probability distributions, statistical hypothesis testing, A/B testing, R, SAS.
  - Big Data & Data Engineering: SQL, relational modeling, ETL/ELT pipelines, Spark, Hadoop concepts, Talend awareness.
  - Cloud & Deployment: AWS ecosystem (EC2, S3, Lambda, API Gateway), Docker, FastAPI, CI/CD.
  - Model Evaluation & Business Value: Metric calibration (Precision, Recall, ROC-AUC, F1), ROI translation.

---

## 2. Target Role B: Nuwave-Style Production AI Engineer Archetype
- **Profile:** Modern Production AI Systems Engineer specializing in Agentic workflows, GraphRAG, Cloud-native microservices, and AI safety/governance.
- **Core Technical Requirements:**
  - Languages: Python (Deep), TypeScript (Strong), Bash.
  - Generative AI & Retrieval: LLM fine-tuning (LoRA/QLoRA), RAG, GraphRAG, Vector databases (Pinecone, Qdrant, Chroma), Hybrid Search, Semantic chunking.
  - Agents & Orchestration: LangGraph, LangChain, Multi-agent collaboration, tool-calling schemas, deterministic fallback workflows.
  - Cloud Infrastructure: AWS & Azure (Entra ID, Azure OpenAI, Serverless, Containers, S3/Blob storage), Terraform / IaC concepts.
  - Production Engineering: Observability, latency/cost budgets, hallucination evaluation, incident response, rollback strategies, ISO/IEC 42001 AI governance standards.
  - Professional Collaboration: Git PR workflows, ADRs (Architecture Decision Records), system cards, technical documentation.

---

## 3. The 6-Level Evidence Ladder for Portfolios & Resumes
To ensure absolute truthfulness and defensibility:
1. `Practice Only`: In-browser sandbox or tutorial completion (NOT CV-eligible).
2. `Skill Evidence`: Verified problem set / transfer challenge score.
3. `Technical Artifact`: Isolated runnable repository or script with unit tests.
4. `Portfolio Project`: Comprehensive end-to-end project with documentation, data provenance, and evaluation metrics.
5. `Professional Evidence`: Production-deployed API, containerized workflow, benchmark analysis, or PR review record.
6. `Signature Project`: Novel architecture, research reproduction/ablation, or enterprise-grade multi-agent / RAG deployment with full system card.
