# AI system
Provider abstraction `AIProvider` (Puter OpenAI-compatible endpoint, Bearer PUTER_AUTH_TOKEN). ModelRouter: pro = PUTER_MODEL_NAME (default deepseek/deepseek-v4-pro) for examiner/lecturer/challenger; flash = PUTER_FAST_MODEL_NAME (default deepseek/deepseek-v4-flash) for hints, English, notebook, oral, supervisor.
MentorOrchestrator: Student → Lead Mentor policy → action→specialist routing → owner-scoped context (lesson, prerequisites, mastery, error types, high-help count, active project, target role) → one model call → persisted thread. No recursive agent calls. Guardrails: attempt-first, anti-reassurance, dependency detector (≥3 consecutive no-attempt requests), no diagnosis, untrusted retrieved text. Failure modes surface as `not_configured`, `provider_error`, `timeout`, `rate_limited` and are stored on the thread.
Help levels recorded per attempt: none, hint, guidance, concept_reminder, worked_example, full_explanation; only none/hint count as independent.
