# Harvard reality check

**Question: does Harvard offer a bachelor's degree named "Artificial Intelligence Engineering"?**
Not found. The verified undergraduate structure is a Computer Science concentration built from tagged
requirement areas plus mathematical preparation, alongside SEAS engineering programmes. AI appears as a
requirement tag and as advanced coursework, not as a standalone named undergraduate degree.

**What the verified CS concentration structure implies for this curriculum**
- Programming depth (two distinct programming requirements) → `orig-m1-python` + `cs-foundations-core`.
- Formal reasoning (discrete mathematics, algorithms, computational limitations) → `cs-foundations-core`.
- Systems → `cs-systems`.
- Computation and the world → `security-responsible-ai` and the case/ethics integration across projects.
- Advanced CS (four courses numbered 1000+) → `orig-m6-ml`, `orig-m7-deep-learning`, `llm-engineering`,
  `rag-engineering`.
- Mathematical preparation (linear algebra, probability/multivariable) → `orig-m2-math-stats` +
  `harvard-math-depth`.

**Harvard Extension School (separate institution, verified)**
Artificial Intelligence Graduate Certificate: four online graduate courses — foundations of AI;
advanced NLP and machine learning; deep learning and computer vision; AI ethics, governance and law;
B grade minimum; three-year completion window. Mapped onto `orig-m6-ml`, `orig-m7-deep-learning` and
`security-responsible-ai` as Harvard Extension layers, never presented as Harvard College content.

**Gaps the original curriculum had relative to this structure**
Formal reasoning and proof, C and the memory model, data structures and algorithmic analysis, systems
and concurrency, database internals, statistical inference depth, optimisation theory, research method,
software-engineering practice, cloud, security and governance. All were added as additive layers; none
of the original content was removed to make room.
