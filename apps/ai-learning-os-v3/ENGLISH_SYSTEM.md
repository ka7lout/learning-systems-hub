# English system

Default site language: English. Default content mode: Standard Technical English — authentic
terminology, never diluted. Alternative modes: B1–B2 (simplified surrounding language, canonical terms
preserved) and Arabic (Arabic explanation with English technical terms retained). Vocabulary assistance
annotates terms inline with a simple definition, an Arabic meaning and a usage example.

## Seven tracked dimensions
reading · listening · writing · speaking · interaction · technical vocabulary · professional
communication. Each is counted and self-rated separately. **No CEFR level is ever inferred**, and a
level is never derived from vocabulary count.

## Activities
PR descriptions, spoken architecture defence, interview answers, client discovery exchanges, incident
updates, documentation summarisation, targeted vocabulary use and shadowing. The activities operate on
the learner's own engineering work, so the technical learning is itself the language classroom.

## Speaking lab
Browser speech recognition is used when the runtime provides it; otherwise the learner types or
transcribes and the UI says so. No pronunciation score is fabricated from unavailable technology.
Strong self-rated responses create `technical-english` / `communication` skill evidence.
