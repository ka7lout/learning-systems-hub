# Content model
`curriculum_nodes` (stage | module | lesson | topic) with sourceCategory ∈ {original, harvard_college, harvard_extension, industry, research}, priority ∈ {core, support, advanced, specialization, industry, research}, level, why, objectives, content sections (kind: why/concept/example/failure/connection/case, optional code), notebook {mustWrite, recommended, optional}, harvardMapping[] {course, title, school, exactMatch, depth, harvardAdds, weAddBeyond, status, sourceId}, sourceRefs[], masteryCriteria[], version, verifiedAt.
`node_prerequisites` is a DAG (Kahn check at seed). `practice_items` types: free_recall, explain_why, choose_method, transfer, case_decision, calculation, derivation, predict_output, code_reading, debugging, algorithm_tracing, complexity_analysis, diagnose_failure, design_review — difficulty A–F, rubric[], reference, isTransfer.
Source status model: confirmed_current | confirmed_historical | likely_not_verified | not_found | design_decision | research_hypothesis.
