# Technical English System

Default language is English and default mode is Standard Technical English: authentic professional terms with clear surrounding explanations. Optional modes are B1–B2 English, Arabic explanation, vocabulary assistance and English training.

Tracked dimensions are Reading, Listening, Writing, Speaking, Interaction, Technical Vocabulary and Professional Communication. Vocabulary count alone never establishes a CEFR level.

Seeded vocabulary entries give a concise definition, example and optional Arabic meaning. English practice is integrated into engineering work: read a bug report, write a PR/README, explain an architecture, present a project, answer an interview question, discover client requirements, or respond to an incident.

Browser speech recognition/playback varies by browser and locale. Until a supported capability is implemented and tested, the application must not invent pronunciation scores. Text-based explanation is an honest fallback; audio upload is not enabled in this release.
