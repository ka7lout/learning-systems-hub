# Career engine

Flow: target role → stated requirements → skill taxonomy → learner evidence → gap → learning task →
project → interview evidence → readiness statement.

## Role blueprints
Two reference roles are encoded from the specification: a Navisoft-style broad AI/statistics/data-platform
role and a NUWAVE-style production AI role (cloud, RAG/GraphRAG, agents, identity, IaC, observability,
ISO/IEC 42001 concepts). Both are stored with `verificationStatus = likely_not_verified`, a snapshot date
and a note stating that live availability, seniority and location restrictions were not re-verified.
Snapshots are additive; historical snapshots are never overwritten.

## Gap analysis
Each role's skills are partitioned into: independently demonstrated (≥1 independent evidence item),
in progress (mastery recorded, no independent evidence) and gap (nothing). The progress bar reports
evidence coverage against the rubric, explicitly described as a statement about recorded evidence and
not a hiring prediction.

## CV value rules
A CV line is generated only when it maps to a real artefact (repository, deployment, report). With no
qualifying artefact the engine says plainly that no bullet can be produced. There is no "impact
generator" and no invented metrics.

## Readiness language
Permitted: "you have demonstrated the evidence required by this readiness rubric".
Forbidden: any promise or probability of employment.
