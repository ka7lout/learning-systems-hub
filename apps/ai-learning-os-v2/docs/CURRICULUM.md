# Curriculum
Source of truth: `src/content/curriculum.ts`. Module 1–8 sections and topics are kept word for word (34 sections). Module 3 and 5 session-count mismatches are resolved as 2 sessions per section, and the duplicated Module 7 heading is merged, all without removing anything. Tiers: CORE / SUPPORT / ADVANCED / SPECIALIZATION / INDUSTRY EXTENSION / RESEARCH. Classifying a topic never deletes it.
Additive layers: Harvard College mapping (CS 50/20/1240/61/1200/1210/1810/1820, math/stat requirements, ECE selected), Harvard Extension (AI Graduate Certificate categories), Industry (SWE, languages, cloud, big data, MLOps, RAG/agents, security, English, career, freelancing), Research.
Every Harvard claim has a status: confirmed_current / confirmed_historical / likely_not_verified / not_found.
Framework strategy: TensorFlow/Keras is primary (as in the original), PyTorch is secondary (Extension layer), scikit-learn handles classical ML, Hugging Face covers LLMs.
