# English system

Default mode is Standard Technical English. B1–B2 mode simplifies surrounding language while keeping canonical terms. Vocabulary assistance adds a definition, optional Arabic meaning, example sentence, and pronunciation support only when the browser/provider can provide it.

Track reading, listening, writing, speaking, interaction, technical vocabulary, and professional communication separately. Vocabulary count is never a CEFR claim. Technical English practice is embedded in code reviews, bug reports, architecture explanations, project presentations, interviews, client discovery, and incident response.
