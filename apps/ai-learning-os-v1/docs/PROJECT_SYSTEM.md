# Project system
Catalog of 25 projects on a 10-level ladder. Student instances store environment links (repo, codespace, colab, kaggle, dataset + license, deployment, report), notes (provenance, schema, limitations, bias/leakage risks), a definition-of-done checklist (status "done" is gated on it) and evidence (commit, pull_request, deployment, report, metric, demo, test_run, model_card) classified practice_only → signature_project. Evidence creates skill_evidence; practice_only does not. GitHub is the source of truth for code; Codespaces/Colab/Kaggle for compute — no remote code execution on the server.
