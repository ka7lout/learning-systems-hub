# Project System

## Original project catalog

All 21 learner-provided project ideas are preserved: skin disease prediction; face recognition/detection/verification; text classification; stock-market prediction; sign-language classifier; real-time object detection; breast-cancer detection; brain-tumor detection; GAN image generation; library management system; Uber data analysis; Superstore dashboard; HR dashboard; bank-loan data analysis; sales database; credit-card fraud detection; Titanic prediction; house-pricing prediction; chatbot; document summarization; RAG system.

Ideas are not completed outcomes. Risk notes flag medical, biometric, hiring/HR, credit and financial applications. Use real public data/APIs only under their licenses/terms; document provenance, acquisition date, schema, limitations, bias and leakage risks.

## Evidence ladder

Practice only -> skill evidence -> technical artifact -> portfolio project -> professional evidence -> signature project. Classification depends on actual submitted evidence, not project title or self-report alone.

## Definition of Done

Problem/constraints and acceptance criteria; documented data source and limits; reproducible code; tests; valid evaluation; failure analysis; security and privacy review; documentation; deployment tested where relevant; monitoring and rollback plan where relevant; portfolio evidence and an oral defense.

## Execution boundary

The website manages brief, milestones, review and evidence links. Code of meaningful size runs in GitHub Codespaces, local development, Colab or Kaggle. No arbitrary remote code execution occurs on the Next.js server. GitHub OAuth, repository contents, datasets, demos and deployments are not fabricated when unconnected.
