# Project system

Projects increase from Python engineering through data analysis, SQL/data pipelines, classical ML, deep learning, CV/NLP, LLM/RAG, agents, production AI, and research.

A serious project requires a problem definition, constraints, source/license/acquisition metadata, schema/data dictionary, baseline, tests, evaluation, failure analysis, security review, documentation, deployment/monitoring plan where applicable, rollback consideration, and portfolio evidence.

The website tracks briefs, milestones, review, evidence, and portfolio linkage. It does not execute arbitrary student code or impersonate a cloud ML cluster.
