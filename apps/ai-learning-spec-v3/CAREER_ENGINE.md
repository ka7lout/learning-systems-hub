# Career engine

The career workflow is Target Role → Current Requirements → Skill Taxonomy → Student Evidence → Gap → Learning Task → Project → Interview Evidence → Readiness.

The seeded role snapshots are explicitly labeled reference roles and `likely_not_verified`; they are not employment guarantees. Requirements, location restrictions, seniority, and market conditions must be re-verified on each dated snapshot.

CV bullets are eligible only when linked to a repository, commit/PR, deployment, report, metric source, or other real evidence. The platform may report “demonstrated by this rubric”; it must never promise hiring.
