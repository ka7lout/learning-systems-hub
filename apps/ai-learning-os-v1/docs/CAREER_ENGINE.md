# Career engine
Target role → role_requirements (hard | preferred | familiarity) → skill_evidence (assessment, delayed_transfer, project, deployed_artifact, oral, interview_sim) → status per skill: missing / developing / competent (strength ≥2 with ≥2 independent items) / demonstrated (strength 3: deployment, PR, test run). Readiness is a rubric; the UI never promises employment. Role blueprints (Navisoft-style, NUWAVE-style) are encoded from the student-supplied lists and flagged `likely_not_verified` until the live postings are re-checked; no market statistics are displayed.
