## Harvard reality

The source register records Harvard College CS concentration requirements separately from Harvard Extension AI/Data Science offerings. Current verified material emphasizes programming, formal reasoning, systems, computation and the world, advanced CS, and mathematical preparation. CS50 is modeled as one course experience with lectures, sections, problem sets, quizzes, and a final project; it is not treated as the whole CS degree.

## IHLS protocol

WHY → QUESTION → ATTEMPT → GUIDED LEARNING → RECALL → FEEDBACK → PRACTICE → TRANSFER → CASE → BUILD → DELAY → RECALL AGAIN. The operating state changes task size, scaffolding, density, and transitions; it does not diagnose the learner.
